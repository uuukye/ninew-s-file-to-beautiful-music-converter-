# ninew-s-file-to-beautiful-music-converter-
<b>a file to music converter! and reverts perfectly! (i hope)</b>

this original name was supposed to be miniprogram1 because I was going to make a small project, just converting bytes to frequency levels, but no! 
it was way harder and much more complicated than i thought, especially when I had to revert the wav file to the original bytes.

Basically, it's a file to beautiful music converter! It converts any file (i hope) thats that's not over 200kb, into a audio that humans cannot understand by listening to it. But when you revert it, it comes out perfect!

You can use this to like make secret messages, like tell them to go to this project and put the super secret WAV file and get the file or text!
